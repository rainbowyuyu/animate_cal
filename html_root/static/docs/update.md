## 最新：智能体上线

**智能体**已全站上线：用自然语言描述需求（或上传公式图片），系统将自动跳转到对应页面并执行任务（识别、生成动画、打开 LaTeX / Manim 工作台等）。详见下方 **v 0.3.5** 更新说明。

### 近期优化（动态计算与 LaTeX）
- **数学表达式字号**：移除计算页「大中小」按钮，字号改为在 **设置 → 动态计算** 中的滑动条调节，旁边显示数值（rem），默认小字号便于看全长题。
- **看全题目**：数学表达式区域支持纵向滚动与横向滚动，长题目可完整查看。
- **LaTeX 解析**：全站改用 **KaTeX** 渲染（与 ChatGPT、Claude、豆包等一致），公式整齐、正确、好看；支持 `$...$` 与 `$$...$$`。
- **题解 Manim 提示词**：`solution_visualization_prompt` 与 `formular_prompt`、`visualization_prompt` 等章节与编号规范统一。
- **智能体功能与示例**：保留原有「仅识别」「识别并保存」等全部功能，并补充完整具体示例（仅识别不保存、识别并告诉结果、打开 LaTeX/Manim/拓展库、完整解题演示、多种组合流程等）。
